Overview

PHT (Premise Health Test) is a tool to assist technicians in the diagnosis of any premise. It is an enhancement over the Home Integrity Check (HIC). PHT validates both DOCSIS parameters and video devices (if FBC capable).

  • Full band spectrum visibility for capable chipsets.
  • Multimedia over Coax Alliance (MoCA) scoring.
  • In-depth FLUX/ICFR graphs to help locate network impairments in the home.
  • OFDM and OFDMA measurements.
  • Integration with National Watchtower (NWT) to identify open tickets or network events.

Actual US TX

Accounts for Upstream Extended Transmit (UET) capabilities and compression. If a device transmits at max power and still cannot reach the CMTS at the requested input level (generally 0 dBmV), it goes into compression.

Calculation: Actual US TX = Current transmit level + |CMTS RX Level|
Example: 51 dBmV (TX) + |-3.5 dBmV (RX)| = 54.5 dBmV (Fails > 54)

Partial Bonding

If any US or DS channel becomes impaired, the device stops using it ("partial bonding"), triggering a failure.

  • DOCSIS 3.0: Registration state of 4 indicates healthy usage. State 1, 2, 3, or 5 = impaired/partial.
  • DOCSIS 3.1: OFDMA Ranging Status of 4 is required.

FLUX ICFR Indicators (>= 3 dB)

OUTLET (Fail)

Fault isolated to a specific outlet feeding the device. The fault is unique to this outlet.

HOME (Fail)

Fault isolated to a common point in the home feeding multiple (but not all) devices.

DROP (Fail)

Fault isolated to a common point feeding all devices. Neighbors checked clean.

SOLO (Fail)

Cannot isolate to specific location or drop. Neighbors checked clean (not a network issue).

NETWORK (Pass w/ Override)

Fault isolated to the network. At least 2 of 10 neighboring accounts have a matching ICFR signature. No RTM required unless other signal thresholds fail.

FBC Impairments

Full Band Capture identifies frequency-specific issues in the DS spectrum.

Suckout: A sharp dip in the spectrum graph. Any impairment other than Adjacent Channel Power will fail PHT unless overridden by NWT.

MoCA PHY Rates

Actual physical layer bit rate between nodes.

  • Fail: < 200 Mbps (Gateway to Client).
  • Segmented: Missing expected devices.
  • Bridged: Devices from different accounts communicating (requires POE filter).

FM Ingress

Checks for noise spikes in the 88-108MHz band (requires 5+ spikes).

  • Moderate (Pass): Spikes >= 10dB above average amplitude.
  • Severe (Fail): Any spike >= 15dB above average amplitude.

PHT Pause (Throttling)

PHT throttles tests to prevent unresponsive responses from polling too rapidly. Limit: 1 test every 90 seconds per account.

You will receive a Buzz alert if paused. If remaining time is < 3 seconds, a retry is allowed without an alert.

Device States

  • Unresponsive Device: Expected to be online, offline for < 24 hours. Verify power and billing match.
  • Unrecognizable Device: Active in billing but offline for > 24 hours. Verify if it's still in the home. Move to disabled status if unused.
  • Incomplete D3P Data: Missing data due to poor cell connectivity. Re-run test.

Analysis Types

Filter Possible noise filter blocking an upstream. Check tap and ensure home is ingress-free before removing.
Outage All DOCSIS devices unresponsive AND a matching NWT outage event is in progress.
POE Filter Foreign devices communicating on the MoCA network. Likely a missing or improperly placed POE filter.
SNR Delta CM US SNR is > 5 dB lower than the port level US SNR, indicating a device or in-home issue.
True Node CMTS/US interfaces used by devices do not match billing/NCP listings. Indicates a billing error.
ALL OUT 2 or more devices all unresponsive/offline, with NO matching NWT outage event. Check main signal feed.

Troubleshooting & Overrides

General RTM Submission Guidelines

Before submitting a Refer To Maintenance (RTM) ticket, ensure testing is done directly at the customer's tap to prove the issue originates from the network and not the premise wiring.

  • Actual US TX: Verify levels fail at the tap.
  • Partial Bonding: Lock meter in DOCSIS 3.0/3.1 directly at tap; must fail bonding at the tap to RTM.
  • FLUX ICFR: Run a test lead directly from tap to device. If ICFR fails directly from the tap, submit RTM.
  • MoCA: You CANNOT enter a network maintenance RTM for MoCA failures.

Pass w/ Override Conditions

If an account fails PHT, it can be overridden if it is listed as an affected account in an ongoing NWT (National Watchtower) event that matches the exact failure reason.

US TX / DS SNR / DS RX Overridden if NWT event matches failure type (e.g. Node-wide DS SNR issue).
Spectra Suckout / Wave Overridden if known HFC network event is active in NWT.
US SNR Does NOT trigger a Pass w/ Override condition. Work with local maintenance team.
