Mid-Split Troubleshooting & Remediation

Overview

This document defines the actions and tools needed to properly identify and remediate issues regarding mid-split activation.

Required Tools & Hardware

  • ABS mid-split compliant Unity Gain Amplifier — CIFA number: 306293

In-Home Assessment Test (iHAT) Tool

iHAT is a CONNECT tool developed to help determine whether a premise can support mid-split. When a node is converted to mid-split, iHAT determines which homes can activate spectrum without interruption and which need remediation.

Identified Issue Definition / Solution
OFDMA Ranging Issue / Blocked Carrier The most likely cause is a drop amplifier blocking the mid-split spectrum, making it unusable by the gateway. Requires a TC to remove or replace with a mid-split drop amplifier.
Video Interference Interference from an XG device in the home. Caused by low port-to-port isolation in the soft drop system. Requires a TC to ensure the passive drop network meets specs.
No XG Devices iHAT performs the test but will not be able to provide video interference information.
XB3 / BWG or older model Customer does not meet the minimum requirements to perform a test.

Eligibility Requirements

  • Customers must have a Comcast approved DOCSIS 3.1 or greater DOCSIS device able to tune to the mid-split upstream (OFDMA) spectrum (39.4-85 MHz).
  • To ensure that the home is mid-split compliant, a series of actions and validations must occur to ensure a great customer experience.

TC Flow: Tiling

Diagnostic Steps

  1. Verify the customer's complaint.
  2. Verify the customer is in an enabled mid-split node (Check Plant Info in Tech360).
  3. Verify the customer has a Comcast-approved DOCSIS 3.1+ device.
  4. Verify that tiling is present at a lower channel, less than 200 MHz.
  5. Power off the mid-split capable gateway/modem:
    • If tiling is still present: Not caused by mid-split. Troubleshoot normally.
    • If no tiling: Caused by mid-split device. Proceed below.
  6. Follow M&P for TC resolution. Correct the drop network to meet OES.
  7. Troubleshoot existing PHT failures. If PHT fails for OFDMA, run the OFDMA widget on XM Meter. If failing at the tap, submit an RTM SA.
  8. Once PHT is Pass or Pass w/ Overrides, Mid-split testing becomes available.

Remediation Options

Option 1 - Passive Network or Amplifier

  • Passive Network: Lower loss to common splitter (lowers TX power of XB, raises RX power of STB/XG). Remove unused splitters, terminate ports. Increase port-to-port isolation using OES 1.2 GHz splitters. Consider MoCA passives for multiple XGs.
  • Amplifier Present: Determine if needed. If possible, remove and replace with passive splitter/MoCA passive. If an amp is absolutely needed, replace sub-split amp with a mid-split amplifier.

If this does not resolve tiling, proceed to Option 2.

Option 2 - STB Adjustments & Notch Filters

  • QAM X1 Customers: Convert to All IP (if enabled). 4K customers may need XiD temp + GSK for 4K wireless device.
  • If unwilling to give up QAM X1 (XG1/XG2), use a mid-split notch filter connected directly to the QAM X1 device.
  • Multiple QAM X1s: Replace extras with XiDs, or place a notch filter on each affected XG device.
  • Legacy/TiVo: Place notch filter directly on STB.
  • CRITICAL: Do NOT connect to MoCA devices (XiD/Xi3) or to any XB device.

Limit Notch Filters

Notch filters are a last resort (<1% of customers). Only fixes tiling < 200 MHz, not slow speeds/latency. Use code: INST MIDSPLIT FILTER.

TC Flow: OFDMA Partial Bonding

Formerly known as "Blocked Carrier".

  1. Verify customer's issue.
  2. Verify enabled mid-split node.
  3. Verify DOCSIS 3.1+ device (tunes to 39.4-85 MHz).
  4. Follow M&P for TC resolution.
  5. Verify & correct drop network to OES.
  6. Troubleshoot PHT failures.

Mitigation Order of Preference

Option 1: Remove the drop amplifier and reconfigure the customer's network using only passive splitters.

Option 2: Remove the drop amplifier and reconfigure using a MoCA passive splitter (follow OES MoCA specs).

Option 3: Replace the existing sub-split amplifier with a mid-split amplifier.
